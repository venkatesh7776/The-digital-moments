# The Digital Moments — website

Next.js (App Router) · Motion · Lenis smooth scroll · Vercel Analytics

## Run
    npm install
    npm run dev        # http://localhost:3000
    npm run build && npm start

## Where to edit content
- `src/data/site.ts` — WhatsApp number, Instagram link, domain, nav
- `src/data/catalog.ts` — themes, video invitations, Moments QR, client projects, testimonials
  (add an object to an array; no layout changes needed. Testimonials stay hidden while the list is empty.)
- `src/app/globals.css` — design tokens (colours, type, spacing, radii, shadows, motion) and components

## Assets
- `public/brand` — trimmed logo, monogram and sparkle layers (generated by `scripts/assets.mjs`, `scripts/split-sparkle.mjs`)
- `public/themes` — theme screenshots · `public/video` — web-compressed invitation · `public/qr` — gallery photos
